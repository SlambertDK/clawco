Install Clawco

One command on a Mac or Linux machine. It needs Node 22.6 or newer, git and npm. If one is missing, the installer tells you the one command that fixes it.

1. Run this in a terminal

curl -fsSL https://clawco.work/install.sh | bash

Read the script first

Run the same command again later to update. The code is updated; your settings and your data are not touched.

The installer's messages are in Danish for now.

2. Open Clawco

The installer starts Clawco as a background service and prints its address, by default http://127.0.0.1:8750. The Start room asks for a model key and walks you on from there.

Let your AI run it

Tell Claude Code, Codex or another AI to run this command. It asks no questions, and its last line is one line of JSON that tells the AI the address and what is still missing. You only paste your model key in the Start room.

curl -fsSL https://clawco.work/install.sh | bash -s -- --fra-ai

What you need

  • A Mac or a Linux machine with Node 22.6 or newer, git and npm. Or Docker with the Compose plugin.
  • All you need is a key from a model provider, or a model running on your own machine. There is no other agent or program to install.
  • Optional: Tailscale, to reach Clawco from your phone.

Look first

To see the plan without changing anything, add --dry-run:

curl -fsSL https://clawco.work/install.sh | bash -s -- --dry-run

Prefer Docker?

From a copy of the Clawco source folder, one Compose command starts Clawco as a container, reachable on this machine only.

docker compose up -d --build

Advanced: use your own Hermes agent

Clawco comes with its own agent. If you already run a Hermes agent and want Clawco to use it, add --agent-url with its address. The installer then asks for its key, hidden.

curl -fsSL https://clawco.work/install.sh | bash -s -- --agent-url http://127.0.0.1:8642

Run it in your own cloud

No machine at home? Clawco can run on a small server in a cloud account you own. It is reachable only on your own Tailscale net, with no open port. Your data lives on that server and never with us.

Cost: about 4–5 euro a month, paid to Hetzner for its smallest server. Clawco itself and a personal Tailscale account are free.

You need a Hetzner Cloud account with an API token, and a Tailscale account with HTTPS turned on and a single-use auth key saved in a file.

In a terminal on a Mac or Linux machine, download the script and look at the plan first. This changes nothing and needs no token:

curl -fsSL https://clawco.work/egen-sky/hetzner.sh -o hetzner.sh
bash hetzner.sh --dry-run --authkey-fil tskey.txt

To create the server, put your Hetzner token in HCLOUD_TOKEN and run the script without --dry-run:

export HCLOUD_TOKEN=your-hetzner-token
bash hetzner.sh --authkey-fil tskey.txt

The server has no SSH and no open port. It is replaced, not repaired: delete it in the Hetzner console and run the script again.
